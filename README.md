# 주간 철강 및 철강원료 동향

👉 **사이트 바로가기: https://take5000k.github.io/steel-weekly/**

매크로 · 철강 · 철광석 · 석탄의 주간 동향과 흐름 전망을 정리하는 개인 리포트 사이트.

- 공개 데이터만 사용하며, 출처를 지표마다 명시
- 개인 분석이며 특정 기관의 견해나 투자 권유가 아님

## 구성
- `index.html` — 사이트 (주간 리포트 · 가격 전망 · DB센터 · 리포트 아카이브)
- `data/` — 지표 데이터 (예정)
- `reports/` — 호별 리포트 (예정)

> 시범 운영 중. DB센터는 실제 공개 데이터, 주간 리포트·가격 전망·아카이브는 아직 샘플.
